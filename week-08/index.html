Project Notes

  • Focus: Tiled grid using loops, HSB color variation, and non-linear motion with noise() and sin().
  • Interaction controls: Press 1 and 2 to change density. Move the mouse to subtly adjust margins.
  • Process: Watched The Coding Train and Maxim's p5JS tutorials on youtube to reinforce basic concepts. Created sketch in p5.js web editor, embedded to html and uploaded to GitHub repo.

Documented Learnings

While building my pattern and movement sketch, I ran into two small problems. They ultimately helped me get started and start having some fun with motion. The first was a syntax mistake: I accidentally used a minus sign instead of a division symbol when calculating each cell’s width and height, which caused the program to draw one giant rectangle instead of a tiled grid. The second issue happened later when adding motion. As I added sin() and noise() functions, my shapes spun around in unexpected ways. I realized that the x and y coordinates were in the wrong spot on the canvas. I left my shape coordinates as (x, y) even though I had already translated the drawing origin with a push() and translate(), function which made the shapes rotate around at a skewed perspective with the grid moving off the canvas.

Fixing this problem helped me understand which details could completely change the rhythm of a composition. When I started poking around making tiny adjustments and re-ran the sketch, the pattern started to click into place and the motion felt balanced again. This point was when it got exciting to see how different values in code directly affected visual rhythm and composition and I started to get more organic animations. I'm still in early days, learning and reinforcing basic concepts of variables and functions for generative design, but I'm beginning to see how the code logic and aesthetics are connecting as I get familiar with types of code blocks and functions. Just gotta keep playing around and having fun with it.
